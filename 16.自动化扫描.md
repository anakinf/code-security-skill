# 16. 自动化安全扫描

## Python 安全扫描

### Bandit

Python 安全静态分析工具，检测常见安全漏洞。

```bash
# 安装
pip install bandit

# 扫描整个项目
bandit -r src/ -f json -o bandit-report.json

# 扫描并输出到终端
bandit -r src/ -lll  # 仅显示中高危

# CI 中使用
bandit -r src/ --fail-on HIGH --skip B101
```

关键规则：

| 规则 | 检测内容 | 严重程度 |
|------|----------|----------|
| B101 | assert 语句（生产环境禁用） | Medium |
| B102 | exec() 使用 | High |
| B103 | set_bad_file() | High |
| B201 | eval() 使用 | High |
| B301 | pickle.loads() | High |
| B303 | yaml.load() | Medium |
| B307 | eval-like 函数 | High |
| B310 | os.popen() | Medium |
| B320 | subprocess shell=True | High |
| B322 | 输入注入 | Medium |
| B401 | import_hook | Medium |
| B405 | xml.etree.cElementTree | Medium |
| B506 | yaml.load() 不安全 | High |
| B602 | subprocess 未检查 | Medium |
| B604 | 任意文件写 | Medium |

### Semgree

通过规则引擎检测安全漏洞。

```bash
# 安装
pip install semgrep

# 使用官方规则
semgrep --config=registry/python --error src/

# 自定义规则
semgrep --config=.semgrep/ --error src/
```

自定义规则示例（`.semgrep/sql-injection.yaml`）：

```yaml
rules:
  - id: sql-injection
    patterns:
      - pattern: |
          cursor.execute("..." + $USER_INPUT + "...")
    message: "可能的 SQL 注入"
    languages: [python]
    severity: ERROR
```

### Safety / pip-audit

依赖漏洞扫描。

```bash
# Safety（商业版，基础版免费）
pip install safety
safety check -r requirements.txt

# pip-audit（开源）
pip install pip-audit
pip-audit -r requirements.txt
```

## Node.js 安全扫描

### npm audit

```bash
# 检查依赖漏洞
npm audit

# 修复兼容性更新
npm audit fix

# 仅修复补丁版本
npm audit fix --production

# 输出 JSON 格式
npm audit --json
```

### yarn audit

```bash
yarn audit
```

## 容器安全扫描

### Trivy

```bash
# 安装（macOS）
brew install trivy

# 扫描镜像
trivy image your-image:tag

# 扫描文件系统
trivy fs /path/to/project

# 扫描仓库
trivy repo https://github.com/your/repo

# 输出 JSON
trivy image --format json --output trivy-report.json your-image:tag

# CI 中断构建
trivy image --exit-code 1 --severity HIGH,CRITICAL your-image:tag
```

### Docker Scout

```bash
# 分析镜像
docker scout quickview your-image:tag

# CI 中使用
docker scout cves your-image:tag
```

## CI/CD 集成示例（GitHub Actions）

```yaml
name: Security Scan

on:
  push:
    branches: [main, develop]
  pull_request:
    branches: [main]

jobs:
  security:
    runs-on: ubuntu-latest

    steps:
      - uses: actions/checkout@v4

      - name: Bandit Scan
        run: |
          pip install bandit
          bandit -r src/ --fail-on HIGH

      - name: pip-audit
        run: |
          pip install pip-audit
          pip-audit -r requirements.txt

      - name: npm audit
        run: |
          npm audit --audit-level=high

      - name: Trivy Scan
        uses: aquasecurity/trivy-action@master
        with:
          scan-type: 'fs'
          scan-ref: '.'
          format: 'sarif'
          output: 'trivy-results.sarif'
          severity: 'HIGH,CRITICAL'

      - name: Upload SARIF
        uses: github/codeql-action/upload-sarif@v3
        with:
          sarif_file: 'trivy-results.sarif'

      - name: Dependency Review
        uses: actions/dependency-review-action@v4
        if: github.event_name == 'pull_request'
```

## Dependabot 配置

```yaml
# .github/dependabot.yml
version: 2
updates:
  - package-ecosystem: "pip"
    directory: "/"
    schedule:
      interval: "weekly"
    open-pull-requests-limit: 10
    labels:
      - "dependencies"
      - "python"
    allow:
      - dependency-type: "direct"

  - package-ecosystem: "npm"
    directory: "/"
    schedule:
      interval: "weekly"

      interval: "weekly"
```

## 自动化门禁策略

| 阶段 | 工具 | 通过标准 |
|------|------|----------|
| 代码提交 | pre-commit hook | 无高优漏洞 |
| PR 创建 | Bandit + Semgrep | 无 HIGH 漏洞 |
| PR 合并 | Trivy + pip-audit + npm audit | 无 CRITICAL 漏洞 |
| 每日 | Dependabot | 自动创建 PR |
| 每周 | 全量扫描 | 修复所有 HIGH+ 漏洞 |

## 本地快速检查脚本

```bash
#!/bin/bash
# scripts/security-check.sh

echo "=== Bandit Python Scan ==="
bandit -r src/ -ll || exit 1

echo "=== pip-audit ==="
pip-audit -r requirements.txt || exit 1

echo "=== npm audit ==="
npm audit --audit-level=high || exit 1

echo "=== Safety Check ==="
safety check -r requirements.txt || exit 1

echo "=== Done ==="
```
