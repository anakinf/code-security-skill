# Python + React 安全开发规范手册

## 概述

本手册面向 Python (FastAPI/Django) + React 技术栈的企业级项目，涵盖从编码实现到部署上线的全链路安全规范。

## 适用对象

- 后端开发工程师（Python）
- 前端开发工程师（React）
- DevOps / SRE
- 安全工程师
- 技术管理者

## 使用方式

1. **新项目**：从 01 开始依次落地，在架构阶段引入安全设计
2. **存量项目**：重点使用 15_上线Checklist.md 逐项排查，按优先级修复
3. **CI/CD 集成**：参考 16_自动化扫描.md 配置流水线安全门禁
